**状态：⬜ 未开始** · 预计成本 3~5 天 · 风险 中 · 建议拆成三次独立提交

---

## 背景

三件互相独立的事，共同点是「不做也能玩，但做了更像一个产品」。

### E1 · 绘制调用

`zombie._build_body()` 里有 **12 次 `_make_box()`**，每只丧尸 = 12 个 `MeshInstance3D`。Godot 4 Forward+ 不会自动实例化合批，因此：

```
15 只尸潮  ≈ 180 draw call
30 只无尽  ≈ 360 draw call
```

这是目前最大的一项固定开销。F3 覆盖层已经能读出实时数值，改造前后可直接对比。

### E2 · 本地化

全项目 **1679 处**中文字符串硬编码在脚本里（界面、卡牌描述、提示语）。若上架 Steam 或想让英文用户玩，必须抽成 `tr()` 键。

### E3 · 测试

`.gitignore` 目前还忽略了 `test_*.gd`；项目没有任何自动化测试或 CI。

## E1 · 丧尸网格合并

### 方案对比

| 方案 | draw call / 只 | 代价 |
|---|---|---|
| 现状（12 个 MeshInstance） | 12 | — |
| **合并躯干/腿等静态部件，保留双臂** | 3 | 手臂摆动动画保留，改动小 |
| 全部合并 + 顶点色 | 1 | 失去分段动画，需要顶点着色器做摆动 |

推荐先做中间方案（12 → 3）。

### 实施

1. `_build_body()` 里改为收集 `Array[Transform3D + BoxMesh + Color]`
2. 用 `SurfaceTool` 逐盒 append，运行一次 `commit()` 得到 `ArrayMesh`
3. 每个部件用顶点色区分（材质改为一个共享的 `StandardMaterial3D` + `vertex_color_use_as_albedo`）
4. 手臂仍保留为独立 `MeshInstance3D`（2 个）
5. 精英变大、变色的逻辑改为整体 `scale` + 材质替换，不再逐盒改

### 验收

- [ ] F3 读数：15 只尸潮的 draw call 从约 180 降到 **< 70**
- [ ] 丧尸外观与现在一致（截图对比四种类型 + 精英三词缀）
- [ ] 受击血珠、死亡倒地、池化复用的视觉表现不变
- [ ] 不出现「材质串色」（顶点色 + 共享材质要确认每个实例独立）

## E2 · 本地化

### 实施

1. 新建 `localization/strings.csv`（key, zh, en）
2. 界面文本改为 `tr("UPGRADE_DMG_NAME")` 等键名；卡牌名称与描述从 `.tres` 的 key 取（依赖阶段 B）
3. 语言切换：`TranslationServer.set_locale("en")`，设置面板加一项
4. 中文作为默认语言，键名保持英文

### 验收

- [ ] `grep -P '[\x{4e00}-\x{9fa5}]' scripts/*.gd` 的命中数 < 50（仅剩注释与调试输出）
- [ ] 切英文后：菜单、HUD、三选一、暂停、结算四处无中文残留、无文字溢出
- [ ] 卡牌描述折行在两种语言下都不超出卡片

### 风险

中文比英文短，英文描述容易溢出。必须复用 `_wrap_text()`（已支持按像素宽度折行），并给英文文案定字数上限。

## E3 · 测试

### 最低目标：一个冒烟测试

```gdscript
# tests/smoke_test.gd —— 用 gdUnit4 或 headless 脚本运行
# 1. 加载 main.tscn
# 2. 断言无 error 输出
# 3. 强制刷一波，断言 zombies_alive > 0
# 4. 模拟 60 帧，断言无崩溃
```

配套改动：`.gitignore` 里的 `test_*.gd` 需要放开或改为 `tests/` 白名单。

### 可选的数值单测

- `mag_capacity()`：不同武器 + 弹匣扩容卡的组合
- `meta_cost()`：0~5 级的价格序列
- 无尽曲线：`pow(1.10, 10)` 的取值断言

### 验收

- [ ] 一条命令跑完（`godot --headless --script tests/run.gd`）
- [ ] 测试失败时退出码非 0（可接 CI）
- [ ] 不依赖真实渲染，可在无显示器环境运行
