# 阶段 D · 敌人状态机与导航

**状态：⬜ 未开始** · 预计成本 3~5 天 · 风险 高（行为与平衡会变）

---

## 背景

`zombie.gd` 904 行承载了 7 种敌人 + BOSS 三阶段 + 双 BOSS 变体 + 精英词缀，主循环 `_physics_process` 单函数 115 行，里面用 early-return 串起了三条互斥分支：

```gdscript
if zombie_type == "spitter":      _spitter_think(...); return
if zombie_type == "boss" and boss_variant != "": _boss_variant_think(...); return
# 通用追击 / 近战
if zombie_type == "charger": ...
if zombie_type == "boss": _boss_update_phase() ...
```

全项目 `zombie_type ==` 共 **9 处**。再加第 8 种敌人，需要在 4~5 个函数里同步改。

另一个更影响体验的问题：**没有寻路**。所有敌人朝玩家直线移动 + `move_and_slide()`，在地图有墙（每张图 5~6 面）时会挤在墙角，玩家很容易「溜墙角」无伤清怪。

## 目标

1. 把行为从 `if` 链改成「状态机 + 每类型行为对象」
2. 加入导航网格，让敌人绕障
3. 保持现有数值与手感不变（除绕障带来的路径变化）

## 目标结构

```
scripts/enemy/
├── enemy_brain.gd         # 状态机：IDLE / CHASE / ATTACK / STAGGER / DEAD
├── behaviors/
│   ├── behavior_base.gd   # 接口：think(delta, ctx)
│   ├── normal.gd          # 普通：直追
│   ├── runner.gd          # 疾行
│   ├── exploder.gd        # 自爆
│   ├── tank.gd            # 重装
│   ├── charger.gd         # 冲锋 + 撞击自爆
│   ├── spitter.gd         # 吐酸（保持距离）
│   └── boss.gd            # 三阶段 + 变体
└── affix.gd               # 精英词缀（狂暴 / 分裂 / 吸血）
```

`zombie.gd` 保留「身体拼装 + 视觉 + 掉落 + 池化」，行为全部移到 `behaviors/`。

## 实施步骤

### D1 · 抽状态机骨架（不改行为）

把现有的「追击 / 攻击 / 眩晕 / 死亡」四段逻辑搬进 `EnemyBrain`，仍然只调用当前 `zombie.gd` 的函数。目标是**行为完全不变化**，只是把调用关系理顺。

### D2 · 逐类型迁移行为

按复杂度排序：normal → runner → tank → exploder → charger → spitter → boss。每迁一个，跑一局对照行为。

### D3 · 导航接入（先不做运行时烘焙）

- 在 `wave_manager._build_map()` 之后，用 `NavigationRegion3D` + `NavigationMeshSourceGeometryData3D` 做**一次烘焙**（地图是静态的，不需要动态更新）
- 敌人挂 `NavigationAgent3D`，目标点每 0.3 秒刷新一次（每帧刷新会很贵）
- 距离玩家 < 6 米时直接切直线追击（近距离绕障反而会显得迟钝）

### D4 · 调参

绕障会让到达时间变长，需要补偿：略微提高 `speed`，或让「远程型（spitter）」保留 8~15 米的射程带逻辑。

## 验收标准

- [ ] 7 类敌人 + BOSS 三阶段 + 双 BOSS 变体的行为逐项对照旧版本（见下表）
- [ ] 在「工地」「医院」这类多墙地图，敌人不再长时间卡在墙角；玩家绕柱跑动时敌人能跟上来
- [ ] 第 3 波尸潮 15 只同屏，FPS 不低于修改前（用 F3 覆盖层对比）
- [ ] `zombie_type ==` 出现次数 ≤ 2（只在身体拼装与视觉选择里）
- [ ] 对象池复用正常：新一局的敌人不会带着上一局的行为状态

### 行为回归表

| 类型 | 必须保持不变的点 |
|---|---|
| 普通 / 疾行 | 追击速度、近战间隔、伤害 |
| 自爆者 | 3.5 米内自爆、50 伤害、不可被提前引爆 |
| 重装者 | 1.3 倍体型、200 血 |
| 冲锋者 | 10 米触发、6.5 速度、4 米硬半径、80→20 衰减 |
| 吐酸者 | 8~15 米射程带、1.2 秒前摇、3 米酸液 15 伤害 |
| BOSS | 50% / 25% 两次阶段切换、酸液环 8 发、红圈 1 秒引爆 30 伤害 |
| 变体 | 冲锋型不停歇撞击、吐酸型 9~16 米 + 每 8 秒酸液环 |

## 风险与回滚

**高风险**：这是唯一会改变玩家实际体验的阶段——敌人更快到达、不再卡墙，整体难度会上升。建议：

1. D1、D2 只重构不改行为，单独提交，可安全回滚
2. D3 导航单独提交，用「关掉导航」的开关做 A/B 对比
3. 平衡调整（D4）最后做，且一次只动一个数

## 前置依赖

**必须先完成阶段 B**。否则每迁一种敌人，都要同时在 `.tres`、状态机、行为脚本三处维护数值。
